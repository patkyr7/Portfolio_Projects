
## Shorts Analyzer

## Description
A Python tool, which the user can analyze their videos' data with a CSV file.

## Features
- Counts total Views and/or Likes
- Counts avarage views and/or likes every 10/20/30 videos
- Finds best performing video 
- Compares platforms

## How to run
1. Place your CSV Folder in the Data Folder.
2. Run main.py

## Requirements
1. Windows 8 or later
2. Python 3.13.7 or later
