
## Fortune Teller: The Game


## Description
Fortune Teller is my very first project. It is a story-text-based game. Objective is to experience all the random events, that can happen.

## Features
- Utilizes a number of functions for the player to input their own, personalized info of age, gender and name, while putting logical barriers on the inputs.
- Utilizes Colorama's Fore and Style to give the feeling of Dialog.
- Keeps track of statistics like how many days you have played, ammount of deaths, money, how many events you have seen among others.
- Utilizes the module Random to give a variety of fortunes to the player.
- Utilizes the module of time in order to partly immerse the player.


## How to run
1. Run Fortune_Teller.py

## Requirements
